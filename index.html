Assembly Notes

Step-by-step guidance for building and installing your drawers.

1. Cabinet Box Assembly: Cut side panels to full height. Install top/bottom panels between sides. Add nailer strips: top front/back, bottom back pieces (flush with back), and perpendicular pieces. Nailers create rabbet for back panel if used. Total finished box dimensions match specifications above.
2. Drawer Box Assembly - Groove Setup: Cut grooves in drawer front and sides 18-19mm from bottom edge. Groove depth should be half the wall thickness (e.g., 12mm wall = 6mm groove). Groove width matches bottom panel thickness. Back panel sits above groove.
3. Drawer Box Assembly - Construction: Join front, back, and sides with dados or rabbet joints. Slide bottom panel into grooves from back. Screw bottom panel into drawer back from underneath. Ensure box is square before fasteners set.
4. Undermount Slide Installation: If using toe kick, build separately (100mm tall) and install level first. Mount slide cabinet brackets to cabinet sides at heights shown in Position Heights table. Ensure slides are level and parallel. Attach drawer brackets to drawer box bottom.
5. Drawer Front Attachment: After testing drawer operation, attach overlay fronts using adjustable mounting brackets. Overlay fronts extend - beyond opening on all sides. Fine-tune alignment using slide adjustments.
